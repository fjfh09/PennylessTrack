# PennylessTrack

## Descripción del proyecto

PennylessTrack es un proyecto de aplicación para la gestión de finanzas personales, cuyo objetivo es facilitar el registro, seguimiento y control de ingresos y gastos.

La aplicación permitirá organizar los movimientos económicos y mejorar la gestión del presupuesto personal.

## Tecnologías utilizadas

Actualmente se utilizan las siguientes herramientas:

- **Git:** control de versiones.
- **GitHub:** alojamiento del repositorio.
- **GitHub Projects:** organización de tareas mediante Kanban.
- **GitHub Issues:** gestión de tareas e incidencias.

Las tecnologías de desarrollo de la aplicación se definirán más adelante.
