# PennylessTrack

## Descripción del proyecto

PennylessTrack es un proyecto de aplicación orientada a la gestión de finanzas personales, cuyo objetivo es facilitar el registro, seguimiento y control de ingresos y gastos.

La aplicación pretende ayudar a los usuarios a organizar su información económica y mejorar la gestión de su presupuesto personal.

## Objetivos

- Registrar y consultar ingresos y gastos.
- Organizar los movimientos económicos por categorías.
- Facilitar el seguimiento del presupuesto personal.
- Proporcionar una interfaz sencilla e intuitiva.
- Aplicar buenas prácticas de desarrollo y seguridad informática.

## Tecnologías utilizadas

Las tecnologías y herramientas previstas para el desarrollo y la gestión del proyecto son:

- **Git:** control de versiones.
- **GitHub:** alojamiento y gestión del repositorio.
- **GitHub Projects:** organización de tareas mediante un tablero Kanban.
- **GitHub Issues:** seguimiento de tareas, incidencias y mejoras.
- **GitHub Actions:** herramienta prevista para automatizar pruebas y verificaciones.

Las tecnologías específicas de implementación de la aplicación se definirán durante el desarrollo.

## Metodología de trabajo

El proyecto utiliza una metodología Kanban basada en las siguientes fases:

1. **Backlog:** tareas pendientes de planificación.
2. **Ready:** tareas preparadas para comenzar.
3. **In Progress:** tareas en desarrollo.
4. **In Review:** tareas pendientes de revisión y validación.
5. **Done:** tareas completadas y verificadas.

Cada tarea se gestiona mediante GitHub Issues y se relaciona con una rama de desarrollo y una Pull Request para mantener la trazabilidad de los cambios.

## Seguridad

Durante el desarrollo se tendrán en cuenta buenas prácticas de seguridad, como la protección de información sensible, la revisión del código y la prevención de la exposición accidental de credenciales.
